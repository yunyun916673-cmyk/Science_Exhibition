# 甜度悖論的權衡：結合 Levenshtein 距離與鍵盤網格距離之蜜碼生成模型研究

## 研究動機
聚焦中小企業登入防護需求，探討 蜜碼 （honeywords) 的「甜度悖論」權衡：如何在確保攻擊者無法辨識真偽的同時，讓合法使用者因日常手誤不致頻繁遭系統誤判。完整的後端系統防禦架構與動態延遲機制收尾於未來展望，確保科展核心聚焦於演算法與核心模型的科學驗證。
近年密碼系統研究逐漸重視密碼外洩後的防禦。相關研究顯示，AI 已可分析蜜碼特徵並嘗試辨識真實密碼，也有研究開始利用大型語言模型生成更具真實性的蜜碼。因此，本研究以較輕量的方式，結合 Levenshtein 距離與鍵盤網格距離，探討蜜碼不可辨識性、合法使用者誤判率與系統成本之間的最佳平衡。
## 研究問題
 • 結合 Levenshtein 距離與鍵盤網格距離後，能否在維持蜜碼對攻擊者不可辨識性的同時，降低合法使用者因日常誤觸產生的誤判率？
 • 當蜜碼數量增加時，系統在安全性、誤判率與計算成本之間的取捨，是否存在其最佳平衡點？
研究假設
 • 假設一：透過引入鍵盤實體幾何距離，能有效緩解蜜碼的甜度悖論，使模型在模擬人類打字習慣時，保持蜜碼的混淆度，且對自然手誤給予合理容忍，降低誤判率。
 • 假設二：隨著蜜碼數量增加，防禦阻擋率呈現先升後趨於平緩的邊際效益遞減。同時系統的計算與記憶體開銷隨之增長，因此在防禦效益與系統成本之間存在一個最佳的區間。
## 變因與對照組設計
 • 操縱變因：鍵盤網格距離的權重係數與容許閾值、蜜碼生成數量。
 • 應變變因：攻擊阻擋率、合法誤判率、峰值記憶體消耗量、平均登入延遲、演算法平均運算耗時、CPU使用率、單次驗證字串比對次數。
 • 控制變因：密碼長度分佈、密碼字元集範圍、固定打字錯誤率模型、標準臺灣主要鍵盤佈局、固定每次模擬樣本數。
 • 對照組：
   • 對照組一：完全不使用 蜜碼的傳統系統。
   • 對照組二：使用傳統固定 Levenshtein 距離的蜜碼機制（不考慮鍵盤網格實體距離）。
   • 實驗組：結合鍵盤網格距離與優化過濾機制的增強型蜜碼系統。
## 評估指標
 • 攻擊阻擋率、合法誤判率、具體的系統效能數據（運算時間、記憶體與比對次數）。
## 16 週研究進度時程
為了預留足夠的時間彈性，
將預計的進度時程調至16週。
第 1-4 週：以 C++ 實作演算法核心（Levenshtein 距離、網格座標轉換與候選生成）。
第 5-8 週：執行分組模擬測試，取得不同參數與蜜碼數量下的原始數據。
第 9-11 週：以 Python 進行數據分析與視覺化，解讀甜度悖論之平衡點。
第 12-14 週：撰寫書面報告，進行總結、口說展板與模擬問答準備。
第 15-16 週：補充實驗與結果驗證，針對異常數據或不足之處進行修正。
