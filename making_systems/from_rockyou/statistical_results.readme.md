* 鍵盤組合： 比對 keyboard connect.txt。
依匹配字元長度轉換為對應數量的 B（例如：QWERTY 轉換為 BBBBBB）。 
* 英文單字： 比對 english_10514_top.txt。
不區分大小寫，1 個單字轉換為 1 個 W（例如：iloveyou 轉換為 WWW）。 
* 連續數字規律： 觸發條件為長度 < 3，依字元長度轉換。
* 連續相同（例如：1111）➔ 轉換為 k（如 kkkk） 
* 連續升冪（例如：123）➔ 轉換為 u（如 uuu） 
* 連續降冪（例如：321）➔ 轉換為 d（如 ddd） 
* 單一字元： 未符合上述規律的剩餘字元（包含長度 <3 的連續數字）。 
* 大寫英文 (A-Z) ➔ 轉換為 U 
* 小寫英文 (a-z) ➔ 轉換為 L 
* 一般數字 (0-9) ➔ 轉換為 N 
* 特殊符號 (如 @, !, #) ➔ 轉換為 S 
* 比對優先順序與邏輯： 由左至右進行貪婪掃描（取最長匹配），優先級別為：鍵盤組合 > 英文單字 > 連續數字規律 > 單一字元。
